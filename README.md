# YASHODAY CAREER OS

## Interactive Career Guidance & Career Exploration Platform

A modern, interactive career guidance platform designed for students studying in rural Maharashtra, India.

### 🚀 Features

- **Interactive Home Screen** with animated galaxy and Earth
- **Educational Modules** for Class 9-12, Graduation, and Post-Graduation
- **Career Explorer** with 50+ career profiles
- **Scholarship & Exam Database**
- **Admin Panel** for content management
- **Dark Futuristic Theme** with glassmorphism
- **PWA & Offline Support**
- **Production-ready Code**

### 🛠️ Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS, Shadcn UI
- **Animations**: Framer Motion, GSAP, Lottie
- **3D Graphics**: Three.js
- **State Management**: Zustand
- **Icons**: Lucide React

### 📦 Installation

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to see the app.

### 📁 Project Structure

```
src/
├── app/                 # Next.js app router
├── components/          # React components
├── pages/              # Application pages
├── data/               # JSON databases
├── context/            # Context API
├── hooks/              # Custom hooks
├── utils/              # Helper functions
├── types/              # TypeScript types
└── styles/             # Global styles
```

### 🚀 Development

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
- `npm run type-check` - TypeScript type checking
